# Gym Website Demos

Five complete, themed demo websites for one fictional gym (IronCore Fitness Studio, Palasia, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/forge` Classic Trust · `/surge` Modern Animated · `/haven` Warm & Friendly · `/volt` Dark Hardcore · `/form` Minimal Editorial
- Each theme: Home, About, Programs (+ membership plans), Trainers, Transformations, Join & Contact + free-trial WhatsApp booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
